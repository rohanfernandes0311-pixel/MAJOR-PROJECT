# Reporting a security vulnerability

Please report suspected vulnerabilities privately to the project maintainers through the repository host's private security-reporting channel or another contact they have published. Do not post exploit details, credentials, personal data, or an unpatched vulnerability in a public issue.

Include the affected version or commit, the affected component, concise reproduction steps, expected and observed impact, and any mitigation you know. Do not include real user data or live secrets in the report. Maintainers should acknowledge receipt, coordinate a fix, and agree on disclosure timing with the reporter before public disclosure.
